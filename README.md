# 🗳️ Vote AI Dashboard

## 📌 Project Overview

Vote AI Dashboard is an AI-powered Election Analytics and Fraud Detection System developed using Streamlit. The dashboard helps analyze election data, identify fraud risks, compare party performance, and visualize voting patterns through interactive charts and analytics.

---

## 🎯 Objectives

- Analyze election voting data
- Detect potential fraud patterns
- Visualize party performance
- Compare voter turnout across states
- Identify high-risk candidates
- Provide interactive data exploration

---

## 🚀 Features

### 📊 Interactive Dashboard
- Modern Cyberpunk UI
- Animated Background
- Responsive Layout

### 🎛️ Control Panel
- State Filter
- Party Filter
- Risk Category Filter
- Fraud Risk Score Slider
- Candidate Search

### 📈 Data Visualizations
- Party Dominance Analysis (Bar Chart)
- AI Fraud Detection Matrix (Scatter Plot)
- Risk Distribution (Pie Chart)
- Fraud Score Distribution (Histogram)
- Fraud Risk Boxplot
- Correlation Heatmap

### 🚨 Fraud Analytics
- Fraud Risk Score Analysis
- High-Risk Candidate Detection
- Fraud Case Monitoring

### 📥 Data Export
- Download Filtered Dataset

## ⚙️ Installation

Clone the repository:

```bash
https://github.com/NASIR-stack/vote-ai-dashboard
```

Navigate to project folder:

```bash
cd vote-ai-dashboard
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
